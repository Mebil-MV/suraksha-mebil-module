# System Overview

Suraksha is a modular, multi-hazard WebGIS platform.

## High-level flow

Data Sources
→ Data Processing
→ Hazard and Risk Intelligence
→ Backend and PostGIS
→ React Web Application and WebGIS
→ SOS, Alerts, Response and Recovery

## Primary hazard

Landslides are the primary analytical use case.

## Additional hazard

The architecture is designed to support flash floods as an additional hazard type.

## Architectural principle

The platform should remain modular and hazard-agnostic where possible.
