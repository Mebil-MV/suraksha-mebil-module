# Suraksha Frontend Starter

A mock frontend written in React + Typescript + Leaflet!!

## Run

```bash
npm install
npm run dev
```

## Included

- Home dashboard with hazard gauge, quick actions, recent verified activities
- Leaflet WebGIS with mock hazard, exposure, incident and shelter layers
- Long-press SOS beacon and distress toggles
- Node hop telemetry display
- Safety Hub, claims prototype and community tasks
- Profile settings: Hindi/English, offline valley maps, critical alerts, sign out UI
- Report Incident flow
- Building Audit flow
- Incident details

The service functions currently use mock data. Later they will call FastAPI without requiring the pages to be redesigned.
